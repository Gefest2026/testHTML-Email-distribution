# testHTML-Email-distribution
# HTML-редактор и рассылка писем

Настольное приложение на Python для подготовки HTML-писем и отправки персонализированной рассылки через SMTP. Интерфейс построен на PyQt5 и поддерживает тёмную тему.

## Возможности

- Редактирование HTML с автоматическим обновлением предпросмотра.
- Загрузка и сохранение HTML-шаблонов.
- Импорт получателей из CSV и Excel (`.xlsx`, `.xls`).
- Выбор отдельных получателей или всего списка.
- Подстановка данных получателя в текст письма.
- Настройка SMTP-сервера, отправителя и темы письма.
- Отображение прогресса, отмена дальнейшей отправки и итоговый отчёт.

## Установка и запуск

Установите Python и зависимости:

    python -m pip install PyQt5 PyQtWebEngine pandas openpyxl xlrd

Запустите приложение:

    python testhtml.py

## Формат списка получателей

Файл должен содержать колонки `name`, `surname` и `email`. Колонка `card_number` необязательна.

Пример CSV:

    name,surname,email,card_number
    Иван,Иванов,ivan@example.com,12345
    Анна,Петрова,anna@example.com,67890

## Персонализация писем

В HTML-шаблоне доступны переменные:

| Переменная | Значение |
|---|---|
| `{name}` | Имя получателя |
| `{surname}` | Фамилия получателя |
| `{card_number}` | Номер карты, если указан |
| `{year}` | Текущий год |

Пример шаблона:

    <html>
    <body>
        <h1>Здравствуйте, {name} {surname}!</h1>
        <p>Спасибо, что вы с нами.</p>
        <p>Ваш номер карты: {card_number}</p>
        <footer>© {year}</footer>
    </body>
    </html>

Текущая проверка шаблона требует наличия тегов `<html>` и `<body>` без атрибутов.

## Как отправить рассылку

1. Создайте письмо в редакторе или загрузите HTML-шаблон.
2. Проверьте его в окне предпросмотра.
3. Откройте вкладку «Рассылка».
4. Укажите SMTP-сервер, порт, адрес отправителя и пароль.
5. Задайте тему письма.
6. Загрузите список получателей и отметьте нужные строки.
7. Нажмите «Отправить письма выбранным» и подтвердите отправку.

Приложение использует SMTP через SSL. По умолчанию указаны `smtp.yandex.ru` и порт `465`. Для авторизации может потребоваться пароль приложения вашего почтового сервиса.

## Особенности

Письма отправляются последовательно с паузой в одну секунду после успешной отправки. Действуют ограничения выбранного почтового сервиса. Итоговый отчёт показывает число успешных и неудачных отправок; успешная передача SMTP-серверу не гарантирует доставку во входящие.

События работы записываются в `mailer.log`. Не добавляйте в публичный репозиторий пароли, журналы, реальные списки получателей и шаблоны с личными данными.
